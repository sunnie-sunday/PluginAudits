# plugins

Original, unmodified plugin builds, one folder per plugin and version.
They are third-party binaries: this project never commits, downloads, redistributes or links them.
`SHA256SUMS` records only each file's hash and path; sourcing the builds is up to the auditor.

To audit a build, place your copy in its folder (`plugins/<plugin>/<version>/`), either the release zip as-is
(`latest.zip`) or its unzipped files, and check that it is the build the findings describe.
